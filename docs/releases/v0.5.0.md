New firmware for the RFOne and the Airspy R2/Mini (sweep7) fixes a hang when a sweep is restarted quickly,
and Corvus Sweep now says when a board needs it. Corvus Sweep also drives RTL-SDR dongles. `corvus-pluto`
(0.2.4) is unchanged from v0.4.1.

> **Unofficial.** Corvus is not affiliated with, endorsed by or supported by HydraSDR, Airspy,
> Great Scott Gadgets or Analog Devices. **Flashing unofficial firmware is at your own risk.** Back up
> your board's flash first, and read [firmware/README.md](https://github.com/auggiesoft/corvus/blob/v0.5.0/firmware/README.md#flashing).

## What's new

- **Firmware sweep7 (RFOne, Airspy R2 and Mini): update recommended.** On every earlier sweep firmware, a
  sweep restarted right behind another request could leave the board's USB control endpoint wedged, and the
  board hung until it was unplugged. Corvus Sweep restarts the sweep on every settings change, so this could
  happen in normal use; it was seen on an Airspy R2 after anywhere from 7 to 1,334 back-to-back restarts.
  The fix is in the USB code both boards share. With it, an RFOne and an R2 each ran 10,000 back-to-back
  restarts without a hang. The Mini runs the same image as the R2 (tested on the Mini up to sweep5).
- **Also in the firmware (sweep6).** Steps the tuner can't reach (below ~22.7 MHz or above ~1945 MHz) send
  nothing, where older firmware sent blocks labelled with a frequency the tuner wasn't on. Stopping a sweep
  puts the tuner back where it was before. The host libraries refuse plans outside the tuner's range.
- **Older firmware is flagged.** When a board runs a sweep revision older than sweep7, Corvus Sweep's status
  bar says so and what updating fixes (Dismiss hides it for that board until the next start). `--headless`
  and `--serve` print the same note.
- **RTL-SDR dongles.** RTL2832U dongles (RTL-SDR Blog V3/V4, NooElec NESDR, FlightAware Pro Stick and the
  rest librtlsdr knows) show in the radio picker. The first time one is chosen, Corvus Sweep downloads
  librtlsdr from the separate [corvus-rtl](https://github.com/auggiesoft/corvus-rtl) project (about 0.3 MB,
  checked against a SHA-256 built into Corvus Sweep). On Windows it also offers to install the WinUSB driver
  the dongles need, as Zadig would, after a Windows admin prompt. `--get-rtl` does both without a window.
  The PC sweeps the dongle: on two R820T dongles under Linux, about 17 steps a second at 2.4 MSPS, or
  24–1766 MHz in about two minutes (librtlsdr takes ~50 ms to retune; corrected after release from a
  first figure of 270, which counted only the samples read), with the FM stations on the same channels as
  the RFOne's sweep. Clipping is
  reported as for the boards. Dongles sharing a serial are listed as #1, #2…
  **Not yet run on Windows:** the Windows library and driver installer build, but haven't been tried on a
  Windows machine. If they misbehave, please open an issue.
  [app/README.md](https://github.com/auggiesoft/corvus/blob/v0.5.0/app/README.md#rtl-sdr-dongles) has the details.
- **SoapyAirspy** now drops two stream transfers after each retune, like every other SoapySDR module. With
  one, copies of strong signals sometimes showed a step away. The Mini through SoapySDR runs at 44 steps a
  second, down from 76.

## Files

| File | What it is |
|---|---|
| `corvus-sweep-v0.5.0-windows-x64.zip` | Corvus Sweep for Windows 10/11 x64: unzip and run `corvus-sweep.exe`; `--sim` needs no radio |
| `corvus-sweep-v0.5.0-linux-x86_64.tar.gz` | Corvus Sweep for Linux. Unpack and run `./corvus-sweep`; the two libraries ride along for `--usb lib` |
| `corvus-pluto-v0.5.0-armv7.tar.gz` | the Pluto's on-board sweep program (ARMv7 Linux, static), `corvus-pluto` 0.2.4 (unchanged), with `install.sh` and `plutodvb2-quiet.sh` |
| `corvus-fw-v1.0.2-sweep7-rfone.bin` | RFOne firmware (v1.0.2 plus sweep mode), **new** |
| `corvus-fw-v1.0.0-rc10-6-8-gcf1a374-sweep7-airspy.bin` | Airspy R2 **and** Mini firmware, **new** |
| `corvus-host-v0.5.0-linux-x86_64.tar.gz` | libhydrasdr and libairspy with the sweep API, plus the `hydrasdr_*` and `airspy_*` tools |
| `corvus-libhydrasdr-v0.5.0-windows-x64.zip` | libhydrasdr for Windows (MinGW build) |
| `SHA256SUMS` | checksums of all of the above |

The RTL-SDR files aren't part of this release: they're corvus-rtl's
[v0.1.0](https://github.com/auggiesoft/corvus-rtl/releases/tag/v0.1.0), under librtlsdr's licence (GPL-2.0)
and libwdi's (LGPL-3.0).

Remote operation works between v0.4.x and v0.5.0, except that a v0.4.x window can't show a v0.5.0 server's
RTL-SDR dongle, a board kind it doesn't know. Update both for that. Corvus Sweep needs a Vulkan or GL driver
(DirectX 12 on Windows). Source for every binary is this repository at tag `v0.5.0`; each archive's
NOTICE.txt lists the licences.
