unchanged from v0.3.2.

## What's new

- **RX1 / RX2 on the Pluto (`corvus-pluto` 0.2.3).** The Receiver card's **Input** (or `--port RX2`) picks
  the AD936x's second receiver, on a board in 1R1T (the Pluto+ has both on SMA connectors). The board
  switches RX2 in only while it sweeps and hands RX1 back afterwards, so other programs on it never see the
  change. The driver can't set RX2's gain in this mode, so `corvus-pluto` does it itself, in fast and driver
  mode alike, and it changes mid-sweep as RX1's does. Switching input restarts the sweep. Checked so far
  with nothing connected to RX2 (switching, gain and the hand-back); levels with an antenna are to follow.
- **`--port`** for headless runs and scripts: ANT, CABLE1, CABLE2 (RFOne) or RX1, RX2 (Pluto).
- The board's greeting says how many inputs it offers (`inputs=`); `OK CONFIG` echoes the one in use.
  Corvus Sweep 0.3.3 asks for RX2 only from boards that answer for it, and says so otherwise.

| `SHA256SUMS` | checksums of all of the above |

Update the board with the new `corvus-pluto` (`install.sh <board address>`); Corvus Sweep 0.3.3 works with
`corvus-pluto` 0.2.0 and later (RX2 needs 0.2.3). Corvus Sweep needs a Vulkan or GL driver (DirectX 12 on Windows). Source for every
binary is this repository at tag `v0.3.3`; each archive's NOTICE.txt lists the licences.
