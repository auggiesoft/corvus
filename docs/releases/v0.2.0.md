Corvus Sweep for Windows, a built-in USB driver for every board, and a round of display work. The
firmware and host libraries are unchanged from v0.1.0 (the images rebuild byte for byte).

> **Unofficial.** Corvus is not affiliated with, endorsed by or supported by HydraSDR, Airspy or
> Great Scott Gadgets. **Flashing unofficial firmware is at your own risk.** Back up your board's flash
> first, and read [firmware/README.md](https://github.com/auggiesoft/corvus/blob/v0.2.0/firmware/README.md#flashing).

## What's new

- **Built-in USB driver.** Corvus Sweep now talks to the RFOne, Airspy R2/Mini and HackRF One itself
  (pure Rust, ported from libhydrasdr, libairspy and libhackrf), so it needs no library, DLL or libusb.
  On every board it matches its library's noise floor to within 0.1 dB and runs at the same speed.
  `--usb lib` goes back to the libraries.
- **Windows.** `corvus-sweep.exe` is a single file. Every supported firmware asks Windows for WinUSB
  itself, so there is no Zadig step. This first Windows build is cross-compiled and not yet tested on
  Windows hardware, so please report what you find.
- **Picks the board for you.** Without `--board` it uses the first supported board plugged in
  (`--serial` still narrows it).
- **Peak and average modes.** The average is now a time constant in seconds, in dB or in power. The
  peak trace can hold, decay (holds 1 s, then falls at a set dB/s) or track a percentile over a window.
- **3D view** (the button on the waterfall, **W**, or `--3d`): the waterfall as a landscape, with light or
  strong smoothing.
- **Drag the tuned range.** Zoomed all the way out, drag the overview or the frequency axis to move the
  whole sweep.
- **Gesture hints** for the less obvious controls; they go away once you've used each one (Settings).

## Files

| File | What it is |
|---|---|
| `corvus-sweep-v0.2.0-windows-x64.zip` | Corvus Sweep for Windows 10/11 x64: unzip and run `corvus-sweep.exe`; `--sim` needs no radio |
| `corvus-sweep-v0.2.0-linux-x86_64.tar.gz` | Corvus Sweep for Linux. Unpack and run `./corvus-sweep`; the two libraries ride along for `--usb lib` |
| `corvus-fw-v1.0.2-sweep5-rfone.bin` | RFOne firmware (v1.0.2 plus sweep mode), same as v0.1.0 |
| `corvus-fw-v1.0.0-rc10-6-8-gcf1a374-sweep5-airspy.bin` | Airspy R2 **and** Mini firmware, same as v0.1.0 |
| `corvus-host-v0.2.0-linux-x86_64.tar.gz` | libhydrasdr and libairspy with the sweep API, plus the `hydrasdr_*` and `airspy_*` tools |
| `corvus-libhydrasdr-v0.2.0-windows-x64.zip` | libhydrasdr for Windows (MinGW build) |
| `SHA256SUMS` | checksums of all of the above |

Corvus Sweep needs a Vulkan or GL driver (DirectX 12 on Windows). The Linux host tools
still need libusb-1.0. Boards on stock firmware work too, with a slower PC-driven sweep.

Source for every binary, including the GPL firmware and tools, is this repository at tag `v0.2.0`;
each archive's NOTICE.txt lists the licences.
