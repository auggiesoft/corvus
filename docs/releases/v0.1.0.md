First release: firmware sweep mode for the HydraSDR RFOne, the Airspy R2 and the Airspy Mini, the
host libraries with the sweep API, and Corvus Sweep, the live wideband spectrum analyser.

> **Unofficial.** Corvus is not affiliated with, endorsed by or supported by HydraSDR or Airspy.
> **Flashing unofficial firmware is at your own risk.** Back up your board's flash first, and read
> [firmware/README.md](https://github.com/auggiesoft/corvus/blob/v0.1.0/firmware/README.md#flashing):
> recovering a bad flash means opening the case.

## Files

| File | What it is |
|---|---|
| `corvus-fw-v1.0.2-sweep5-rfone.bin` | RFOne firmware (v1.0.2 plus sweep mode). Reproducible: sha256 `10c3508d…ba91ff824` |
| `corvus-fw-v1.0.0-rc10-6-8-gcf1a374-sweep5-airspy.bin` | Airspy R2 **and** Mini firmware (one image; it detects the board at boot) |
| `corvus-sweep-v0.1.0-linux-x86_64.tar.gz` | Corvus Sweep for Linux, with libhydrasdr and libairspy beside it. Unpack and run `./corvus-sweep` (RFOne), `--board airspy` (R2) or `--board mini`; `--sim` needs no radio |
| `corvus-host-v0.1.0-linux-x86_64.tar.gz` | libhydrasdr and libairspy with the sweep API, plus the `hydrasdr_*` and `airspy_*` tools (for flashing, among others) |
| `corvus-libhydrasdr-v0.1.0-windows-x64.zip` | libhydrasdr for Windows (MinGW build). Not yet tested on hardware |
| `SHA256SUMS` | checksums of all of the above |

The Linux binaries need libusb-1.0 and, for Corvus Sweep, a Vulkan or GL driver. Built on Ubuntu 24.04.

## Speed (24–1800 MHz, lock-verified, one board each)

| Board | Rate | Steps | Speed |
|---|---|---|---|
| RFOne | 12 MSPS | 10 MHz | 8.6 GHz/s, ~5 full passes/s |
| Airspy R2 | 10 MSPS | 8 MHz | 6.5 GHz/s, ~3.65 passes/s |
| Airspy Mini | 6 MSPS | 4 MHz | 2.9 GHz/s, ~1.6 passes/s |

Boards on the Corvus firmware still work as normal receivers with other software. Source for every
binary, including the GPL firmware and tools, is this repository at tag `v0.1.0`; each archive's
NOTICE.txt lists the licences.
